<h1 id="口算">口算</h1>
<h2 id="题目描述">题目描述</h2>
<p>王老师正在教简单算术运算。细心的王老师收集了&nbsp;i&nbsp;道学生经常做错的口算题，并且想整理编写成一份练习。编排这些题目是一件繁琐的事情，为此他想用计算机程序来提高工作效率。王老师希望尽量减少输入的工作量，比如&nbsp;5+8&nbsp;的算式最好只要输入&nbsp;5&nbsp;和&nbsp;8，输出的结果要尽量详细以方便后期排版的使用，比如对于上述输入进行处理后输出&nbsp;5+8=13&nbsp;以及该算式的总长度&nbsp;6。王老师把这个光荣的任务交给你，请你帮他编程实现以上功能。</p>
<h2 id="输入格式">输入格式</h2>
<p>第一行一个整数&nbsp;i。</p>
<p>接着的&nbsp;i&nbsp;行为需要输入的算式，每行可能有三个数据或两个数据。</p>
<p>若该行为三个数据则第一个数据表示运算类型，a&nbsp;表示加法运算，b&nbsp;表示减法运算，c&nbsp;表示乘法运算，接着的两个数据表示参加运算的运算数。</p>
<p>若该行为两个数据，则表示本题的运算类型与上一题的运算类型相同，而这两个数据为运算数。</p>
<h2 id="输出格式">输出格式</h2>
<p>输出&nbsp;2×i&nbsp;行。对于每个输入的算式，输出完整的运算式及结果，第二行输出该运算式的总长度。</p>
<h2 id="输入输出样例">输入输出样例</h2>
<p>###输入</p>
<pre><code>4
a 64 46
275 125
c 11 99
b 46 64
</code></pre>

<p>###输出</p>
<pre><code>64+46=110
9
275+125=400
11
11* 99=1089
10
46-64=-18
9
</code></pre>

<h3 id="sprintfsscanf">sprintf&amp;sscanf</h3>
<h4 id="1-sprintf字符串格式化输出">1.&nbsp;<strong><code>sprintf</code>（字符串格式化输出）</strong></h4>
<p><strong>作用</strong>：将格式化的数据<strong>写入字符串</strong>（类似<code>printf</code>输出到屏幕，但<code>sprintf</code>输出到字符串）</p>
<p><strong>格式</strong>：</p>
<pre><code>int sprintf(char *str, const char *format, ...);
</code></pre>

<p><strong>示例</strong>：</p>
<pre><code>char buffer[100];
int a = 10, b = 20, result = 30;

// 将格式化的字符串写入buffer
sprintf(buffer, "%d+%d=%d", a, b, result);
// buffer现在的内容是："10+20=30"
</code></pre>

<p><strong>在我代码中的应用</strong>：</p>
<pre><code>sprintf(exp, "%d+%d=%d", m, n, m+n);
// 将算式和结果写入exp字符串，比如"5+8=13"
</code></pre>

<h4 id="2-sscanf字符串格式化输入">2.&nbsp;<strong><code>sscanf</code>（字符串格式化输入）</strong></h4>
<p><strong>作用</strong>：从字符串中<strong>读取格式化的数据</strong>（类似<code>scanf</code>从键盘读取，但<code>sscanf</code>从字符串读取）</p>
<p><strong>格式</strong>：</p>
<pre><code>int sscanf(const char *str, const char *format, ...);
</code></pre>

<p><strong>示例</strong>：</p>
<pre><code>char input[] = "a 5 8";
char op;
int x, y;

// 从input字符串中读取数据
sscanf(input, "%c %d %d", &amp;op, &amp;x, &amp;y);
// 结果：op='a', x=5, y=8
</code></pre>

<p><strong>在我代码中的应用</strong>：</p>
<pre><code>sscanf(line, "%c %d %d", &amp;ch, &amp;m, &amp;n);
// 从line字符串中解析出字符和两个整数
</code></pre>
